# FinanzRechner — System zur Kostenkalkulation in der Fertigung

**FinanzRechner** ist eine Webanwendung auf Basis von ASP.NET Core zur Berechnung der vollständigen Herstellungskosten von Produkten unter Berücksichtigung von:

- direkten Materialien  
- Stücklisten (BOM – Bill of Materials)  
- Arbeitsplänen (BOP – Bill of Processes)
- Maschinenkosten (Kosten für den Einsatz von Anlagen)  
- Personalkosten (Arbeitskosten der Mitarbeiter)   

Die Anwendung orientiert sich an realen industriellen Lösungen (z. B. SAP/ERP-Systeme).
